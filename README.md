# Cybersecurity Specialization - 42 School

This repository contains all the projects from the Cybersecurity specialization at 42 School.

## PISCINE CYBERSECURITY

The `cybersecurity_piscine` folder contains 8 directories, each with multiple exercises covering different areas of cybersecurity:

### 1. Cybersecurity - Arachnida (Web)

#### Exercice 1 - Spider
A recursive image downloader capable of fetching multiple file extensions such as `.png`, `.jpeg`, `.jpg`, `.bmp`, and `.gif`.

Implemented in **Python**.

### 2. Cybersecurity - ft_otp (OTP)
Implementation of a One-Time Password (OTP) generator and validator.

### 3. Cybersecurity - ft_onion (Web)
Introduction to onion services, anonymity, and hidden services.

### 4. Cybersecurity - Reverse Me (Rev)
Reverse engineering challenges focused on binary analysis.

### 5. Cybersecurity - Stockholm (Malware)
A ransomware-inspired project for understanding encryption and malware behavior.

### 6. (Optional) Cybersecurity - Iron Dome (Malware)
Advanced malware analysis and defensive mechanisms.

### 7. Cybersecurity - Inquisitor (Network)
Network security, packet analysis, and traffic inspection.

### 8. Cybersecurity - Vaccine (Web)
Exploring web vulnerabilities and security exploitation techniques.
